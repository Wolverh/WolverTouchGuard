1. COMPREHENSIVE APPLICATION DESCRIPTION
--------------------------------------------------------------------------------
Wolver Touch Guard is a specialized, hardware-accelerated touch-blocking utility 
built primarily for mobile gamers (specifically 3-finger, 4-finger claw, and palm 
grip players in titles such as Free Fire, Free Fire MAX, PUBG, and Call of Duty).

On bezel-less, high-refresh-rate curved displays (like the Infinix Note 60), 
accidental edge touches, palm sweat, claw fingers brushing the status bar, or 
fingers straying below weapon/crouch buttons constantly cause misfires, camera 
freezes, or pull down the Android Notification Drawer during intense firefights.

Wolver Touch Guard eliminates this problem by overlaying customizable, invisible 
or visible "dead-zone shields" using Android's Accessibility Overlay architecture.

KEY SYSTEM FEATURES:
1. Four Independent Fully-Adjustable Dead Zones:
   - Zone 1 (Left Edge & Palm Guard): Blocks palm rejection errors when holding the phone.
   - Zone 2 (Top Status Bar & Call Guard): Blocks accidental pull-down of notifications, 
     quick settings, or touching incoming WhatsApp/call banners.
   - Zone 3 (Below 3rd-Finger Button): Shields the area directly below upper left/right 
     claw trigger buttons to prevent misclicks.
   - Zone 4 (Mid-Screen / Auxiliary Shield): Protects around joystick or right-side buttons.
   Each zone has independent X, Y, Width, and Height controls down to the single pixel.

2. Fixed-Ratio In-App Screen Radar Monitor:
   - An interactive miniature phone display (20:9 landscape aspect ratio) right inside 
     MainActivity. As you move the sliders or tap zones, you see the exact positioning 
     in real-time without leaving the app.

3. Live Screen Overlay (View / Hide Options):
   - Switch between Edit Mode (red translucent zones with drag handles) and Lock Mode 
     (100% invisible or faint 5% border, silently blocking touches).
   - "View Blockage Bars on Screen" toggle allows viewing the overlays directly inside 
     the configuration app or over games to calibrate them.

4. Interactive Floating Toggle Pill & Quick Action Menu:
   - A movable, collapsible on-screen badge ("LOCKED", "EDIT", "WG").
   - Smart Touch-Through: If the toggle is placed inside a blocked dead zone, the shield 
     detects the touch and immediately forwards it to the toggle, ensuring it is ALWAYS 
     clickable and never gets trapped in its own dead zone!
   - Tap-to-Menu: Tapping the toggle opens a sleek Quick Control Menu with:
     * [Lock Mode]
     * [Edit Mode]
     * [🚫 HIDE THIS TOGGLE] (One-click complete stealth)
     * [Open App Settings]
     * [Dismiss]

5. Hardware Volume Key Emergency Stealth Toggle:
   - Pressing Volume Up + Volume Down together inside any game instantly unhides the 
     toggle or switches between Lock and Edit modes.

6. In-App 1-Click Update System:
   - Background update checker queries version.json and GitHub Releases.
   - If an update is released, a dialog pops up with the changelog.
   - 1-Click direct install without manually browsing GitHub.

7. Permanent Cryptographic Signing Keystore (Zero Package Conflicts):
   - Signed with permanent release.p12 keystore committed to the project.
   - Every build on GitHub Actions or local is signed with the exact same key.
   - Package ID com.wolver.touchguard.pro guarantees clean installs with zero signature 
     or package conflict errors across all versions.

8. Dual Persistent JSON Settings Backup (Zero Data Loss):
   - Whenever any zone bound or setting is changed, an automated background thread 
     syncs settings to an internal JSON backup and external app storage.
   - Survives app updates and reinstalls automatically.

--------------------------------------------------------------------------------
2. SETUP & INSTALLATION GUIDE (INFINIX XOS 16 / ANDROID 14+)
--------------------------------------------------------------------------------
Step 1: Install the APK (Allow installation from unknown sources).
Step 2: Grant Restricted Settings (Crucial on Android 13/14/15/16):
        Go to phone Settings -> Apps -> Wolver Touch Guard.
        Tap the 3 dots in the top right corner -> Tap "Allow restricted settings".
Step 3: Set Battery to Unrestricted:
        Under App Info -> Battery -> Select "Unrestricted" (prevents OS from killing service).
Step 4: Enable Accessibility:
        Open Wolver Touch Guard -> Tap "2. Accessibility" -> Enable "Wolver Touch Guard Service".

    private fun checkAppUpdates(showToastIfLatest: Boolean) {
        tvUpdateStatus.text = "Checking GitHub for updates..."
        tvUpdateStatus.setTextColor(Color.parseColor("#B0B0B0"))

        UpdateManager.check(this) { info ->
            if (info == null) {
                tvUpdateStatus.text = "Could not reach update server. Check internet connection."
                tvUpdateStatus.setTextColor(Color.parseColor("#FF5252"))
                if (showToastIfLatest) {
                    Toast.makeText(this, "Could not check for updates", Toast.LENGTH_SHORT).show()
                }
            } else if (info.hasUpdate) {
                tvUpdateStatus.text = "🚀 New version v${info.latestVersionName} available!"
                tvUpdateStatus.setTextColor(Color.parseColor("#00E676"))
                UpdateManager.showUpdateDialog(this, info)
            } else {
                tvUpdateStatus.text = "● You are running the latest version (v${BuildConfig.VERSION_NAME})."
                tvUpdateStatus.setTextColor(Color.parseColor("#00E676"))
                if (showToastIfLatest) {
                    Toast.makeText(this, "You're already on the latest version!", Toast.LENGTH_SHORT).show()
                }
            }
        }
    }

    private fun showAppSelectionDialog() {
        val pm = packageManager
        val installedApps = pm.getInstalledApplications(PackageManager.GET_META_DATA)

        data class AppEntry(val label: String, val pkg: String)

        val entriesMap = linkedMapOf<String, String>()
        entriesMap["com.dts.freefireth"] = "Free Fire (com.dts.freefireth)"
        entriesMap["com.dts.freefiremax"] = "Free Fire MAX (com.dts.freefiremax)"

        val userApps = installedApps
            .filter { app ->
                val isUserApp = (app.flags and ApplicationInfo.FLAG_SYSTEM) == 0 ||
                        (app.flags and ApplicationInfo.FLAG_UPDATED_SYSTEM_APP) != 0
                isUserApp && app.packageName != packageName
            }
            .map { app ->
                val name = pm.getApplicationLabel(app).toString()
                AppEntry("$name (${app.packageName})", app.packageName)
            }
            .sortedBy { it.label.lowercase() }

        for (item in userApps) {
            entriesMap[item.pkg] = item.label
        }

        val pkgList = entriesMap.keys.toList()
        val labelArray = entriesMap.values.toTypedArray()
        val currentSelected = prefManager.selectedPackages.toMutableSet()
        val checkedItems = BooleanArray(pkgList.size) { index ->
            currentSelected.contains(pkgList[index])
        }

        AlertDialog.Builder(this)
            .setTitle("Select Games for Touch Guard")
            .setMultiChoiceItems(labelArray, checkedItems) { _, which, isChecked ->
                val pkg = pkgList[which]
                if (isChecked) {
                    currentSelected.add(pkg)
                } else {
                    currentSelected.remove(pkg)
                }
            }
            .setPositiveButton("Save") { _, _ ->
                prefManager.selectedPackages = currentSelected
                updateSelectedAppsSummaryText()
                notifyServiceToRefresh()
            }
            .setNegativeButton("Cancel", null)
            .show()
    }

            notifyServiceToRefresh()
        } else {
            tvServiceStatus.text = "● INACTIVE — Enable in Accessibility Settings"
            tvServiceStatus.setTextColor(Color.parseColor("#FF1744"))
        }
    }

    private fun notifyServiceToRefresh() {
        TouchGuardAccessibilityService.instance?.refreshOverlaysVisibilityAndState()
    }

    private fun isAccessibilityServiceEnabled(context: Context, serviceClass: Class<*>): Boolean {
        val am = context.getSystemService(Context.ACCESSIBILITY_SERVICE) as AccessibilityManager
        val enabledServices = am.getEnabledAccessibilityServiceList(AccessibilityServiceInfo.FEEDBACK_ALL_MASK)
        for (service in enabledServices) {
            val serviceInfo = service.resolveInfo.serviceInfo
            if (serviceInfo.packageName == context.packageName && serviceInfo.name == serviceClass.name) {
                return true
            }
        }
        return false
    }
}

            "com.android.systemui",
            "android",
            "com.transsion.gamespace",

            "com.transsion.smartpanel",

    override fun onAccessibilityEvent(event: AccessibilityEvent?) {
        if (event == null) return

        if (event.eventType == AccessibilityEvent.TYPE_WINDOW_STATE_CHANGED ||
            event.eventType == AccessibilityEvent.TYPE_WINDOWS_CHANGED
        ) {
            val detectedPkg = resolveActiveApplicationPackage(event)
            if (detectedPkg.isNotEmpty() && detectedPkg != currentForegroundPackage) {
                currentForegroundPackage = detectedPkg
                refreshOverlaysVisibilityAndState()
            }
        }
    }

    private fun resolveActiveApplicationPackage(event: AccessibilityEvent): String {
        try {
            val interactiveWindows = windows
            if (!interactiveWindows.isNullOrEmpty()) {
                val targetPackages = prefManager.selectedPackages
                for (win in interactiveWindows) {
                    if (win.type == AccessibilityWindowInfo.TYPE_APPLICATION) {
                        val pkg = win.root?.packageName?.toString().orEmpty()
                        if (pkg.isNotEmpty() && targetPackages.contains(pkg)) {
                            return pkg
                        }
                    }
                }
                for (win in interactiveWindows) {
                    if (win.type == AccessibilityWindowInfo.TYPE_APPLICATION) {
                        val pkg = win.root?.packageName?.toString().orEmpty()
                        if (pkg == packageName) {
                            return pkg
                        }
                    }
                }
                for (win in interactiveWindows) {
                    if (win.type == AccessibilityWindowInfo.TYPE_APPLICATION) {
                        val pkg = win.root?.packageName?.toString().orEmpty()
                        if (pkg.isNotEmpty() &&
                            !IGNORED_TRANSIENT_PACKAGES.contains(pkg)
                        ) {
                            return pkg
                        }
                    }
                }
            }
        } catch (_: Exception) {
        }

        val eventPkg = event.packageName?.toString().orEmpty()
        if (eventPkg.isNotEmpty() &&
            !IGNORED_TRANSIENT_PACKAGES.contains(eventPkg)
        ) {
            return eventPkg
        }

        return currentForegroundPackage
    }

    override fun onKeyEvent(event: KeyEvent): Boolean {
        when (event.keyCode) {
            KeyEvent.KEYCODE_VOLUME_UP -> {
                volUpPressed = (event.action == KeyEvent.ACTION_DOWN)
            }
            KeyEvent.KEYCODE_VOLUME_DOWN -> {
                volDownPressed = (event.action == KeyEvent.ACTION_DOWN)
            }
        }
        if (volUpPressed && volDownPressed && overlaysAttached) {
            volUpPressed = false
            volDownPressed = false

            // Vol Up + Vol Down immediately unhides toggle if hidden, or switches modes
            if (prefManager.hideFloatingToggleAlways || prefManager.isPillHiddenManually) {
                prefManager.hideFloatingToggleAlways = false
                prefManager.isPillHiddenManually = false
                Toast.makeText(this, "Floating toggle unhidden!", Toast.LENGTH_SHORT).show()
            } else {
                val nextMode = if (prefManager.currentMode == PrefManager.MODE_LOCK) {
                    PrefManager.MODE_EDIT
                } else {
                    PrefManager.MODE_LOCK
                }
                prefManager.currentMode = nextMode
            }
            refreshOverlaysVisibilityAndState()
            return true
        }
        return super.onKeyEvent(event)
    }

    private fun createOverlayViews() {
        if (overlaysAttached) return

        for (zoneId in 1..PrefManager.TOTAL_ZONES) {
            val config = prefManager.getZoneConfig(zoneId)
            val view = ZoneOverlayView(
                context = this,
                zoneId = zoneId,
                title = config.title,
                onBoundsUpdated = { id, newX, newY, newW, newH ->
                    prefManager.saveZoneBounds(id, newX, newY, newW, newH)
                    val lp = zoneParams[id]
                    val v = zoneViews[id]
                    if (lp != null && v != null && v.parent != null) {
                        lp.x = newX
                        lp.y = newY
                        lp.width = newW
                        lp.height = newH
                        try {
                            windowManager.updateViewLayout(v, lp)
                        } catch (_: Exception) {
                        }
                    }
                }
            )

            // Touch forwarding: ensures clicking the toggle always works even if inside a blocked zone!
            view.isPillAt = { rawX, rawY ->
                val pill = pillView
                if (pill != null && pill.visibility == View.VISIBLE) {
                    val loc = IntArray(2)
                    pill.getLocationOnScreen(loc)
                    val pLeft = loc[0].toFloat()
                    val pTop = loc[1].toFloat()
                    val pRight = pLeft + pill.width.toFloat()
                    val pBottom = pTop + pill.height.toFloat()
                    rawX in pLeft..pRight && rawY in pTop..pBottom
                } else {
                    false
                }
            }

            view.onPillTouchForward = { ev ->
                val pill = pillView
                if (pill != null && pill.visibility == View.VISIBLE) {
                    val loc = IntArray(2)
                    pill.getLocationOnScreen(loc)
                    val copy = MotionEvent.obtain(ev)
                    copy.setLocation(ev.rawX - loc[0].toFloat(), ev.rawY - loc[1].toFloat())
                    pill.dispatchTouchEvent(copy)
                    copy.recycle()
                }
            }

            val params = createBaseLayoutParams(
                x = config.x,
                y = config.y,
                width = config.width,
                height = config.height,
                touchable = true
            )

            zoneViews[zoneId] = view
            zoneParams[zoneId] = params

            try {
                windowManager.addView(view, params)
            } catch (_: Exception) {
            }
        }

        val pill = FloatingPillView(
            context = this,
            onPillTapped = {
                // Clicking the toggle shows the Quick Menu with [Hide Toggle] option!
                showFloatingMenu()
            },
            onCollapseToggled = { collapsed ->
                prefManager.isPillCollapsed = collapsed
                refreshOverlaysVisibilityAndState()
            },
            onHideCompletelyClicked = {

                prefManager.hideFloatingToggleAlways = true
                prefManager.isPillHiddenManually = true
                refreshOverlaysVisibilityAndState()

                ).show()

            onPositionMoved = { newX, newY ->
                prefManager.pillX = newX
                prefManager.pillY = newY
                val lp = pillParams
                val v = pillView
                if (lp != null && v != null && v.parent != null) {
                    lp.x = newX
                    lp.y = newY
                    try {
                        windowManager.updateViewLayout(v, lp)
                    } catch (_: Exception) {
                    }
                }
            }
        )

        val pParams = createBaseLayoutParams(
            x = prefManager.pillX,
            y = prefManager.pillY,
            width = WindowManager.LayoutParams.WRAP_CONTENT,
            height = WindowManager.LayoutParams.WRAP_CONTENT,
            touchable = true
        )

        pillView = pill
        pillParams = pParams

        try {
            windowManager.addView(pill, pParams)
            overlaysAttached = true
        } catch (_: Exception) {
        }
    }

    private fun createBaseLayoutParams(
        x: Int,
        y: Int,
        width: Int,
        height: Int,
        touchable: Boolean
    ): WindowManager.LayoutParams {
        var flags = WindowManager.LayoutParams.FLAG_NOT_FOCUSABLE or
                WindowManager.LayoutParams.FLAG_NOT_TOUCH_MODAL or
                WindowManager.LayoutParams.FLAG_LAYOUT_IN_SCREEN or
                WindowManager.LayoutParams.FLAG_LAYOUT_NO_LIMITS

        if (!touchable) {
            flags = flags or WindowManager.LayoutParams.FLAG_NOT_TOUCHABLE
        }

        val params = WindowManager.LayoutParams(
            width,
            height,
            WindowManager.LayoutParams.TYPE_ACCESSIBILITY_OVERLAY,
            flags,
            PixelFormat.TRANSLUCENT
        )

        params.gravity = Gravity.TOP or Gravity.START
        params.x = x
        params.y = y

        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
            params.layoutInDisplayCutoutMode =
                WindowManager.LayoutParams.LAYOUT_IN_DISPLAY_CUTOUT_MODE_ALWAYS
        } else if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
            params.layoutInDisplayCutoutMode =
                WindowManager.LayoutParams.LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES
        }

        return params
    }

    fun refreshOverlaysVisibilityAndState() {
        if (!overlaysAttached) {
            createOverlayViews()
        }

        val masterOn = prefManager.isMasterEnabled
        val filterOn = prefManager.isAppFilterEnabled
        val allowedPackages = prefManager.selectedPackages
        val mode = prefManager.currentMode

        val isSelfApp = (currentForegroundPackage == packageName) || (currentForegroundPackage.isEmpty())
        val shouldShowForCurrentApp = if (isSelfApp) {
            prefManager.showOverlayInApp || (mode == PrefManager.MODE_EDIT)
        } else if (!filterOn) {
            true
        } else {
            currentForegroundPackage.isNotEmpty() && allowedPackages.contains(currentForegroundPackage)
        }

        val activeOverall = masterOn && shouldShowForCurrentApp
        val opacity = prefManager.editOpacityPercent
        val lockBorder = prefManager.showLockBorder

        for (zoneId in 1..PrefManager.TOTAL_ZONES) {
            val view = zoneViews[zoneId] ?: continue
            val params = zoneParams[zoneId] ?: continue
            val cfg = prefManager.getZoneConfig(zoneId)

            if (!activeOverall || !cfg.enabled || mode == PrefManager.MODE_OFF) {
                view.visibility = View.GONE
            } else {
                view.visibility = View.VISIBLE
                params.x = cfg.x
                params.y = cfg.y
                params.width = cfg.width
                params.height = cfg.height

                if (isSelfApp && mode == PrefManager.MODE_LOCK) {
                    params.flags = params.flags or WindowManager.LayoutParams.FLAG_NOT_TOUCHABLE
                } else {
                    params.flags = params.flags and WindowManager.LayoutParams.FLAG_NOT_TOUCHABLE.inv()
                }

                view.updateState(
                    x = cfg.x,
                    y = cfg.y,
                    w = cfg.width,
                    h = cfg.height,
                    mode = mode,
                    opacityPercent = opacity,
                    lockBorder = lockBorder
                )

                try {
                    windowManager.updateViewLayout(view, params)
                } catch (_: Exception) {
                }
            }
        }

        pillView?.let { pill ->
            val pParams = pillParams ?: return@let
            val shouldHidePill =
                prefManager.hideFloatingToggleAlways ||
                prefManager.isPillHiddenManually ||
                (mode == PrefManager.MODE_LOCK && prefManager.hidePillInLockMode)

            if (!activeOverall || shouldHidePill) {
                pill.visibility = View.GONE
                dismissFloatingMenu()
            } else {
                pill.visibility = View.VISIBLE
                pParams.x = prefManager.pillX
                pParams.y = prefManager.pillY
                pill.updatePillState(
                    mode = mode,
                    collapsed = prefManager.isPillCollapsed,
                    x = prefManager.pillX,
                    y = prefManager.pillY
                )
                try {
                    windowManager.updateViewLayout(pill, pParams)
                } catch (_: Exception) {
                }
            }
        }
    }

    private fun removeAllOverlays() {
        dismissFloatingMenu()
        for ((_, view) in zoneViews) {
            try {
                if (view.parent != null) windowManager.removeView(view)
            } catch (_: Exception) {
            }
        }
        zoneViews.clear()
        zoneParams.clear()

        pillView?.let {
            try {
                if (it.parent != null) windowManager.removeView(it)
            } catch (_: Exception) {
            }
        }
        pillView = null
        pillParams = null
        overlaysAttached = false
    }

    override fun onInterrupt() {
    }

    override fun onDestroy() {
        removeAllOverlays()
        instance = null
        super.onDestroy()
    }
}

package com.wolver.touchguard

import android.annotation.SuppressLint
import android.content.Context
import android.graphics.Canvas
import android.graphics.Color
import android.graphics.Paint
import android.graphics.RectF
import android.view.MotionEvent
import android.view.View
import kotlin.math.max

@SuppressLint("ViewConstructor")
class ZoneOverlayView(
    context: Context,
    val zoneId: Int,
    private val title: String,
    private val onBoundsUpdated: (zoneId: Int, x: Int, y: Int, width: Int, height: Int) -> Unit
) : View(context) {

    companion object {
        private const val HANDLE_NONE = 0
        private const val HANDLE_TOP_LEFT = 1
        private const val HANDLE_TOP_RIGHT = 2
        private const val HANDLE_BOTTOM_LEFT = 3
        private const val HANDLE_BOTTOM_RIGHT = 4
    }

    var isPillAt: ((rawX: Float, rawY: Float) -> Boolean)? = null
    var onPillTouchForward: ((event: MotionEvent) -> Unit)? = null

    private var currentMode: Int = PrefManager.MODE_EDIT
    private var editOpacityPercent: Int = 40
    private var showLockBorder: Boolean = false

    private var posX: Int = 0
    private var posY: Int = 0
    private var zoneW: Int = 200
    private var zoneH: Int = 200

    private val density = resources.displayMetrics.density
    private val handleSizePx = 32f * density
    private val touchSlopHandlePx = 42f * density
    private val minWidthPx = (40f * density).toInt()
    private val minHeightPx = (35f * density).toInt()

    private val fillPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.FILL
    }

    private val borderPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE
        strokeWidth = 2f * density
    }

    private val handlePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.FILL
        color = Color.parseColor("#EEFFFFFF")
    }

    private val textPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.WHITE
        textSize = 11f * density
        isFakeBoldText = true
        setShadowLayer(4f, 0f, 0f, Color.BLACK)
    }

    private val handleRect = RectF()

    private var activeHandle = HANDLE_NONE
    private var initialTouchRawX = 0f
    private var initialTouchRawY = 0f
    private var initialX = 0
    private var initialY = 0
    private var initialW = 0
    private var initialH = 0

    fun updateState(
        x: Int,
        y: Int,
        w: Int,
        h: Int,
        mode: Int,
        opacityPercent: Int,
        lockBorder: Boolean
    ) {
        posX = x
        posY = y
        zoneW = max(minWidthPx, w)
        zoneH = max(minHeightPx, h)
        currentMode = mode
        editOpacityPercent = opacityPercent
        showLockBorder = lockBorder
        invalidate()
    }

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)

        val w = width.toFloat()
        val h = height.toFloat()

        when (currentMode) {
            PrefManager.MODE_EDIT -> {
                val alpha = ((editOpacityPercent / 100f) * 255).toInt().coerceIn(30, 220)
                fillPaint.color = Color.argb(alpha, 255, 23, 68)
                canvas.drawRect(0f, 0f, w, h, fillPaint)

                borderPaint.color = Color.parseColor("#FFFF1744")
                borderPaint.strokeWidth = 2f * density
                canvas.drawRect(1f, 1f, w - 1f, h - 1f, borderPaint)

                handleRect.set(0f, 0f, handleSizePx, handleSizePx)
                canvas.drawRect(handleRect, handlePaint)

                handleRect.set(w - handleSizePx, 0f, w, handleSizePx)
                canvas.drawRect(handleRect, handlePaint)

                handleRect.set(0f, h - handleSizePx, handleSizePx, h)
                canvas.drawRect(handleRect, handlePaint)

                handleRect.set(w - handleSizePx, h - handleSizePx, w, h)
                canvas.drawRect(handleRect, handlePaint)

                val info = "$title [X:$posX Y:$posY | ${zoneW}x${zoneH}]"
                val textY = (h / 2f).coerceIn(20f * density, (h - 10f * density).coerceAtLeast(20f * density))
                canvas.drawText(info, 10f * density, textY, textPaint)
            }

            PrefManager.MODE_LOCK -> {
                if (showLockBorder) {
                    borderPaint.color = Color.parseColor("#18FF1744")
                    borderPaint.strokeWidth = 1.5f * density
                    canvas.drawRect(1f, 1f, w - 1f, h - 1f, borderPaint)
                }
            }

            PrefManager.MODE_OFF -> {
            }
        }
    }

    private fun detectTouchedHandle(localX: Float, localY: Float): Int {
        val w = width.toFloat()
        val h = height.toFloat()

        val nearLeft = localX <= touchSlopHandlePx
        val nearRight = localX >= w - touchSlopHandlePx
        val nearTop = localY <= touchSlopHandlePx
        val nearBottom = localY >= h - touchSlopHandlePx

        return when {
            nearBottom && nearRight -> HANDLE_BOTTOM_RIGHT
            nearTop && nearLeft -> HANDLE_TOP_LEFT
            nearTop && nearRight -> HANDLE_TOP_RIGHT
            nearBottom && nearLeft -> HANDLE_BOTTOM_LEFT
            else -> HANDLE_NONE
        }
    }

    @SuppressLint("ClickableViewAccessibility")
    override fun onTouchEvent(event: MotionEvent): Boolean {
        // If the touch falls on the floating toggle pill, forward it immediately so the toggle is clickable
        if (isPillAt?.invoke(event.rawX, event.rawY) == true) {
            onPillTouchForward?.invoke(event)
            return true
        }

        if (currentMode == PrefManager.MODE_LOCK) {
            return true
        }

        if (currentMode == PrefManager.MODE_OFF) {
            return false
        }

        when (event.actionMasked) {
            MotionEvent.ACTION_DOWN -> {
                initialTouchRawX = event.rawX
                initialTouchRawY = event.rawY
                initialX = posX
                initialY = posY
                initialW = zoneW
                initialH = zoneH
                activeHandle = detectTouchedHandle(event.x, event.y)
                return true
            }

            MotionEvent.ACTION_MOVE -> {
                val dx = (event.rawX - initialTouchRawX).toInt()
                val dy = (event.rawY - initialTouchRawY).toInt()

                val metrics = resources.displayMetrics
                val maxScreenW = metrics.widthPixels
                val maxScreenH = metrics.heightPixels

                when (activeHandle) {
                    HANDLE_BOTTOM_RIGHT -> {
                        zoneW = (initialW + dx).coerceIn(minWidthPx, maxScreenW)
                        zoneH = (initialH + dy).coerceIn(minHeightPx, maxScreenH)
                    }

                    HANDLE_TOP_LEFT -> {
                        val maxNewX = (initialX + initialW - minWidthPx).coerceAtLeast(0)
                        val maxNewY = (initialY + initialH - minHeightPx).coerceAtLeast(0)
                        val newX = (initialX + dx).coerceIn(0, maxNewX)
                        val newY = (initialY + dy).coerceIn(0, maxNewY)
                        posX = newX
                        posY = newY
                        zoneW = (initialW - (newX - initialX)).coerceIn(minWidthPx, maxScreenW)
                        zoneH = (initialH - (newY - initialY)).coerceIn(minHeightPx, maxScreenH)
                    }

                    HANDLE_TOP_RIGHT -> {
                        val maxNewY = (initialY + initialH - minHeightPx).coerceAtLeast(0)
                        val newY = (initialY + dy).coerceIn(0, maxNewY)
                        posY = newY
                        zoneW = (initialW + dx).coerceIn(minWidthPx, maxScreenW)
                        zoneH = (initialH - (newY - initialY)).coerceIn(minHeightPx, maxScreenH)
                    }

                    HANDLE_BOTTOM_LEFT -> {
                        val maxNewX = (initialX + initialW - minWidthPx).coerceAtLeast(0)
                        val newX = (initialX + dx).coerceIn(0, maxNewX)
                        posX = newX
                        zoneW = (initialW - (newX - initialX)).coerceIn(minWidthPx, maxScreenW)
                        zoneH = (initialH + dy).coerceIn(minHeightPx, maxScreenH)
                    }

                    else -> {
                        posX = (initialX + dx).coerceIn(0, (maxScreenW - zoneW).coerceAtLeast(0))
                        posY = (initialY + dy).coerceIn(0, (maxScreenH - zoneH).coerceAtLeast(0))
                    }
                }

                onBoundsUpdated(zoneId, posX, posY, zoneW, zoneH)
                invalidate()
                return true
            }

            MotionEvent.ACTION_UP, MotionEvent.ACTION_CANCEL -> {
                activeHandle = HANDLE_NONE
                onBoundsUpdated(zoneId, posX, posY, zoneW, zoneH)
                return true
            }
        }
        return true
    }
}

import android.graphics.DashPathEffect
import android.graphics.Paint
import android.graphics.RectF
import android.util.AttributeSet
import android.view.MotionEvent
import android.view.View

class ScreenRadarView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    private val density = resources.displayMetrics.density

    var maxVirtualWidth: Float = 2644f
    var maxVirtualHeight: Float = 1208f

    var selectedZoneId: Int = 1
        set(value) {
            field = value
            invalidate()
        }

    var onZoneSelected: ((Int) -> Unit)? = null
    var prefManager: PrefManager? = null

    private val outerFramePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.parseColor("#0D0D0D")
        style = Paint.Style.FILL
    }

    private val screenBezelPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.parseColor("#1C1C1C")
        style = Paint.Style.FILL
    }

    private val borderPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.parseColor("#333333")
        style = Paint.Style.STROKE
        strokeWidth = 2f * density
    }

    private val gridPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.parseColor("#262626")
        style = Paint.Style.STROKE
        strokeWidth = 1f * density
        pathEffect = DashPathEffect(floatArrayOf(6f, 6f), 0f)
    }

    private val zoneFillPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.FILL
    }

    private val zoneStrokePaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE
        strokeWidth = 2f * density
    }

    private val labelPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.WHITE
        textSize = 10f * density
        isFakeBoldText = true
        setShadowLayer(4f, 0f, 0f, Color.BLACK)
    }

    private val phoneScreenRect = RectF()
    private val zoneRect = RectF()

    init {
        val metrics = resources.displayMetrics
        val screenW = metrics.widthPixels.toFloat()
        val screenH = metrics.heightPixels.toFloat()
        maxVirtualWidth = maxOf(screenW, screenH, 2600f)
        maxVirtualHeight = minOf(screenW, screenH, 1200f)
    }

    override fun onMeasure(widthMeasureSpec: Int, heightMeasureSpec: Int) {
        val width = MeasureSpec.getSize(widthMeasureSpec)
        val heightMode = MeasureSpec.getMode(heightMeasureSpec)
        val heightSize = MeasureSpec.getSize(heightMeasureSpec)

        val desiredHeight = if (heightMode == MeasureSpec.EXACTLY) {
            heightSize
        } else {
            // Keep a clean fixed 20:9 phone aspect ratio (approx 2.2:1)
            (width / 2.2f).toInt().coerceIn((140f * density).toInt(), (220f * density).toInt())
        }
        setMeasuredDimension(width, desiredHeight)
    }

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)

        val padX = 6f * density
        val padY = 6f * density
        phoneScreenRect.set(padX, padY, width - padX, height - padY)

        // Draw phone bezel
        canvas.drawRoundRect(phoneScreenRect, 12f * density, 12f * density, screenBezelPaint)
        canvas.drawRoundRect(phoneScreenRect, 12f * density, 12f * density, borderPaint)

        // Draw center screen alignment crosshair lines
        val midX = phoneScreenRect.centerX()
        val midY = phoneScreenRect.centerY()
        canvas.drawLine(midX, phoneScreenRect.top, midX, phoneScreenRect.bottom, gridPaint)
        canvas.drawLine(phoneScreenRect.left, midY, phoneScreenRect.right, midY, gridPaint)

        val prefs = prefManager ?: return
        val radarW = phoneScreenRect.width()
        val radarH = phoneScreenRect.height()

        val scaleX = radarW / maxVirtualWidth
        val scaleY = radarH / maxVirtualHeight

        // Draw unselected zones first
        for (id in 1..PrefManager.TOTAL_ZONES) {
            if (id == selectedZoneId) continue
            drawZoneOnRadar(canvas, prefs, id, scaleX, scaleY, isSelected = false)
        }

        // Draw selected zone on top
        drawZoneOnRadar(canvas, prefs, selectedZoneId, scaleX, scaleY, isSelected = true)

        // Screen watermark text
        labelPaint.color = Color.parseColor("#555555")
        labelPaint.textSize = 8.5f * density
        canvas.drawText("SCREEN MONITOR 2644x1208", phoneScreenRect.left + 8f * density, phoneScreenRect.top + 14f * density, labelPaint)
    }

    private fun drawZoneOnRadar(
        canvas: Canvas,
        prefs: PrefManager,
        zoneId: Int,
        scaleX: Float,
        scaleY: Float,
        isSelected: Boolean
    ) {
        val cfg = prefs.getZoneConfig(zoneId)
        if (!cfg.enabled) return

        val left = phoneScreenRect.left + (cfg.x * scaleX)
        val top = phoneScreenRect.top + (cfg.y * scaleY)
        val right = (left + (cfg.width * scaleX)).coerceAtMost(phoneScreenRect.right)
        val bottom = (top + (cfg.height * scaleY)).coerceAtMost(phoneScreenRect.bottom)

        zoneRect.set(left, top, right, bottom)

        if (isSelected) {
            zoneFillPaint.color = Color.argb(175, 255, 23, 68)
            zoneStrokePaint.color = Color.parseColor("#FFFF1744")
            zoneStrokePaint.strokeWidth = 2.5f * density
        } else {
            zoneFillPaint.color = Color.argb(85, 41, 121, 255)
            zoneStrokePaint.color = Color.parseColor("#882979FF")
            zoneStrokePaint.strokeWidth = 1.5f * density
        }

        canvas.drawRoundRect(zoneRect, 3f * density, 3f * density, zoneFillPaint)
        canvas.drawRoundRect(zoneRect, 3f * density, 3f * density, zoneStrokePaint)

        // Draw zone badge
        labelPaint.color = if (isSelected) Color.WHITE else Color.parseColor("#CCCCCC")
        labelPaint.textSize = 9.5f * density
        val text = "Z$zoneId"
        val textX = (zoneRect.left + 3f * density).coerceAtMost(phoneScreenRect.right - 22f * density)
        val textY = (zoneRect.top + 12f * density).coerceAtMost(phoneScreenRect.bottom - 4f * density)
        canvas.drawText(text, textX, textY, labelPaint)
    }

    override fun onTouchEvent(event: MotionEvent): Boolean {
        if (event.actionMasked == MotionEvent.ACTION_DOWN) {
            val prefs = prefManager ?: return super.onTouchEvent(event)
            val radarW = phoneScreenRect.width()
            val radarH = phoneScreenRect.height()
            val scaleX = radarW / maxVirtualWidth
            val scaleY = radarH / maxVirtualHeight

            for (id in 1..PrefManager.TOTAL_ZONES) {
                val cfg = prefs.getZoneConfig(id)
                if (!cfg.enabled) continue
                val left = phoneScreenRect.left + (cfg.x * scaleX)
                val top = phoneScreenRect.top + (cfg.y * scaleY)
                val right = left + (cfg.width * scaleX)
                val bottom = top + (cfg.height * scaleY)

                val hitRect = RectF(
                    left - 12f * density,
                    top - 12f * density,
                    right + 12f * density,
                    bottom + 12f * density
                )

                if (hitRect.contains(event.x, event.y)) {
                    selectedZoneId = id
                    onZoneSelected?.invoke(id)
                    invalidate()
                    return true
                }
            }
        }
        return super.onTouchEvent(event)
    }
}

import android.annotation.SuppressLint

@SuppressLint("ViewConstructor")
class FloatingPillView(
    context: Context,
    private val onPillTapped: () -> Unit,
    private val onCollapseToggled: (collapsed: Boolean) -> Unit,
    private val onHideCompletelyClicked: () -> Unit,
    private val onPositionMoved: (x: Int, y: Int) -> Unit
) : LinearLayout(context) {

    private val density = resources.displayMetrics.density
    private val tvDragAndStatus: TextView
    private val tvCollapseBtn: TextView
    private val tvHideFullBtn: TextView

    private var currentMode: Int = PrefManager.MODE_EDIT
    private var isCollapsed: Boolean = false

    private var posX: Int = 950
    private var posY: Int = 24
    private var downRawX = 0f
    private var downRawY = 0f
    private var startX = 0
    private var startY = 0
    private var isDragging = false

    init {
        orientation = HORIZONTAL
        gravity = Gravity.CENTER_VERTICAL

        val bg = GradientDrawable().apply {
            setColor(Color.parseColor("#EE121212"))
            cornerRadius = 20f * density
            setStroke((1.5f * density).toInt(), Color.parseColor("#88FFFFFF"))
        }
        background = bg
        val padH = (12 * density).toInt()
        val padV = (6 * density).toInt()
        setPadding(padH, padV, padH, padV)

        tvDragAndStatus = TextView(context).apply {
            setTextSize(TypedValue.COMPLEX_UNIT_SP, 12f)
            typeface = Typeface.DEFAULT_BOLD
            setTextColor(Color.WHITE)
            gravity = Gravity.CENTER
            setPadding((4 * density).toInt(), (2 * density).toInt(), (6 * density).toInt(), (2 * density).toInt())
        }

        tvCollapseBtn = TextView(context).apply {
            text = " – "
            setTextSize(TypedValue.COMPLEX_UNIT_SP, 13f)
            typeface = Typeface.DEFAULT_BOLD
            setTextColor(Color.parseColor("#B0B0B0"))
            gravity = Gravity.CENTER
            val p = (6 * density).toInt()
            setPadding(p, 0, p, 0)
            setOnClickListener {
                isCollapsed = !isCollapsed
                applyVisualState()
                onCollapseToggled(isCollapsed)
            }
        }

        tvHideFullBtn = TextView(context).apply {
            text = " ✕ "
            setTextSize(TypedValue.COMPLEX_UNIT_SP, 12f)
            typeface = Typeface.DEFAULT_BOLD
            setTextColor(Color.parseColor("#FF5252"))
            gravity = Gravity.CENTER
            val p = (6 * density).toInt()
            setPadding(p, 0, p, 0)
            setOnClickListener {
                onHideCompletelyClicked()
            }
        }

        addView(tvDragAndStatus)
        addView(tvCollapseBtn)
        addView(tvHideFullBtn)

        setupTouchHandling()
        applyVisualState()
    }

    @SuppressLint("ClickableViewAccessibility")
    private fun setupTouchHandling() {
        // Touch handling is focused on the status label / pill drag area
        tvDragAndStatus.setOnTouchListener { _, event ->
            handlePillTouch(event)
        }
    }

    private fun handlePillTouch(event: MotionEvent): Boolean {
        when (event.actionMasked) {
            MotionEvent.ACTION_DOWN -> {
                downRawX = event.rawX
                downRawY = event.rawY
                startX = posX
                startY = posY
                isDragging = false
                return true
            }

            MotionEvent.ACTION_MOVE -> {
                val dx = event.rawX - downRawX
                val dy = event.rawY - downRawY
                if (hypot(dx, dy) > (10 * density)) {
                    isDragging = true
                }
                if (isDragging) {
                    val metrics = resources.displayMetrics
                    posX = (startX + dx.toInt()).coerceIn(0, (metrics.widthPixels - width).coerceAtLeast(0))
                    posY = (startY + dy.toInt()).coerceIn(0, (metrics.heightPixels - height).coerceAtLeast(0))
                    onPositionMoved(posX, posY)
                }
                return true
            }

            MotionEvent.ACTION_UP -> {
                if (!isDragging) {
                    if (isCollapsed) {
                        isCollapsed = false
                        applyVisualState()
                        onCollapseToggled(false)
                    } else {
                        // Single click on the toggle opens the Quick Menu with the Hide Option!
                        onPillTapped()
                    }
                }
                isDragging = false
                return true
            }

            MotionEvent.ACTION_CANCEL -> {
                isDragging = false
                return true
            }
        }
        return false
    }

    fun updatePillState(mode: Int, collapsed: Boolean, x: Int, y: Int) {
        currentMode = mode
        isCollapsed = collapsed
        posX = x
        posY = y
        applyVisualState()
    }

    private fun applyVisualState() {
        if (isCollapsed) {
            tvCollapseBtn.visibility = GONE
            tvHideFullBtn.visibility = GONE
            tvDragAndStatus.text = "WG ⚙"
            alpha = 0.65f
            when (currentMode) {
                PrefManager.MODE_LOCK -> tvDragAndStatus.setTextColor(Color.parseColor("#00E676"))
                PrefManager.MODE_EDIT -> tvDragAndStatus.setTextColor(Color.parseColor("#FF1744"))
                else -> tvDragAndStatus.setTextColor(Color.parseColor("#9E9E9E"))
            }
            return
        }

        alpha = 0.95f
        tvCollapseBtn.visibility = VISIBLE
        tvHideFullBtn.visibility = VISIBLE
        when (currentMode) {
            PrefManager.MODE_LOCK -> {
                tvDragAndStatus.text = "LOCKED ⚙"
                tvDragAndStatus.setTextColor(Color.parseColor("#00E676"))
            }
            PrefManager.MODE_EDIT -> {
                tvDragAndStatus.text = "EDIT ⚙"
                tvDragAndStatus.setTextColor(Color.parseColor("#FF1744"))
            }
            PrefManager.MODE_OFF -> {
                tvDragAndStatus.text = "GUARD OFF ⚙"
                tvDragAndStatus.setTextColor(Color.parseColor("#9E9E9E"))
            }
        }
    }
}

                title = "Z3: Below 3rd-Finger"
                defaultX = 220
                defaultY = 270
                defaultW = 420
                defaultH = 330
            }
            else -> {
                title = "Z4: Right of 3rd-Finger"
                defaultX = 460
                defaultY = 85
                defaultW = 380
                defaultH = 515
            }
        }

        return ZoneConfig(
            id = zoneId,
            title = title,
            enabled = isZoneEnabled(zoneId),
            x = prefs.getInt("zone_${zoneId}_x", defaultX).coerceAtLeast(0),
            y = prefs.getInt("zone_${zoneId}_y", defaultY).coerceAtLeast(0),
            width = prefs.getInt("zone_${zoneId}_w", defaultW).coerceAtLeast(40),
            height = prefs.getInt("zone_${zoneId}_h", defaultH).coerceAtLeast(35)
        )
    }

    fun saveZoneBounds(zoneId: Int, x: Int, y: Int, width: Int, height: Int) {
        prefs.edit()
            .putInt("zone_${zoneId}_x", x.coerceAtLeast(0))
            .putInt("zone_${zoneId}_y", y.coerceAtLeast(0))
            .putInt("zone_${zoneId}_w", width.coerceAtLeast(40))
            .putInt("zone_${zoneId}_h", height.coerceAtLeast(35))
            .apply()
        saveBackupToFile()
    }

    fun resetZonesToDefaults() {
        val editor = prefs.edit()
        for (id in 1..TOTAL_ZONES) {
            editor.remove("zone_${id}_x")
            editor.remove("zone_${id}_y")
            editor.remove("zone_${id}_w")
            editor.remove("zone_${id}_h")
            editor.putBoolean("zone_${id}_enabled", id <= 3)
        }
        editor.putInt(KEY_PILL_X, 950)
        editor.putInt(KEY_PILL_Y, 24)
        editor.putBoolean(KEY_PILL_COLLAPSED, false)
        editor.putBoolean(KEY_PILL_HIDDEN_MANUALLY, false)
        editor.putBoolean(KEY_HIDE_TOGGLE_ALWAYS, false)
        editor.putBoolean(KEY_SHOW_OVERLAY_IN_APP, true)
        editor.apply()
        saveBackupToFile()
    }

    // ==========================================
    // PERSISTENT DATA BACKUP & RESTORE SYSTEM
    // Ensures zone coordinates are NEVER lost on update!
    // ==========================================

    private fun getBackupFiles(): List<File> {
        val files = mutableListOf<File>()
        try {
            files.add(File(context.filesDir, BACKUP_FILENAME))
            val extDir = context.getExternalFilesDir(null)
            if (extDir != null) {
                files.add(File(extDir, BACKUP_FILENAME))
            }
        } catch (_: Exception) {
        }
        return files
    }

    @Synchronized
    fun saveBackupToFile() {
        Thread {
            try {
                val json = JSONObject()
                json.put("master_enabled", isMasterEnabled)
                json.put("app_filter_enabled", isAppFilterEnabled)
                json.put("edit_opacity", editOpacityPercent)
                json.put("lock_border", showLockBorder)
                json.put("hide_toggle_always", hideFloatingToggleAlways)
                json.put("show_overlay_in_app", showOverlayInApp)
                json.put("pill_x", pillX)
                json.put("pill_y", pillY)

                val appsArray = JSONArray()
                selectedPackages.forEach { appsArray.put(it) }
                json.put("selected_apps", appsArray)

                val zonesArray = JSONArray()
                for (id in 1..TOTAL_ZONES) {
                    val cfg = getZoneConfig(id)
                    val zObj = JSONObject().apply {
                        put("id", cfg.id)
                        put("enabled", cfg.enabled)
                        put("x", cfg.x)
                        put("y", cfg.y)
                        put("w", cfg.width)
                        put("h", cfg.height)
                    }
                    zonesArray.put(zObj)
                }
                json.put("zones", zonesArray)

                val content = json.toString(2)
                for (f in getBackupFiles()) {
                    f.writeText(content)
                }
            } catch (_: Exception) {
            }
        }.start()
    }

    @Synchronized
    fun restoreBackupFromFile(): Boolean {
        try {
            for (f in getBackupFiles()) {
                if (f.exists() && f.length() > 10) {
                    val content = f.readText()
                    val json = JSONObject(content)
                    val editor = prefs.edit()

                    if (json.has("master_enabled")) {
                        editor.putBoolean(KEY_MASTER_ENABLED, json.getBoolean("master_enabled"))
                    }
                    if (json.has("app_filter_enabled")) {
                        editor.putBoolean(KEY_APP_FILTER_ENABLED, json.getBoolean("app_filter_enabled"))
                    }
                    if (json.has("edit_opacity")) {
                        editor.putInt(KEY_EDIT_OPACITY, json.getInt("edit_opacity"))
                    }
                    if (json.has("hide_toggle_always")) {
                        editor.putBoolean(KEY_HIDE_TOGGLE_ALWAYS, json.getBoolean("hide_toggle_always"))
                    }
                    if (json.has("pill_x")) {
                        editor.putInt(KEY_PILL_X, json.getInt("pill_x"))
                    }
                    if (json.has("pill_y")) {
                        editor.putInt(KEY_PILL_Y, json.getInt("pill_y"))
                    }

                    if (json.has("zones")) {
                        val zonesArray = json.getJSONArray("zones")
                        for (i in 0 until zonesArray.length()) {
                            val zObj = zonesArray.getJSONObject(i)
                            val id = zObj.getInt("id")
                            editor.putBoolean("zone_${id}_enabled", zObj.getBoolean("enabled"))
                            editor.putInt("zone_${id}_x", zObj.getInt("x"))
                            editor.putInt("zone_${id}_y", zObj.getInt("y"))
                            editor.putInt("zone_${id}_w", zObj.getInt("w"))
                            editor.putInt("zone_${id}_h", zObj.getInt("h"))
                        }
                    }

                    editor.apply()
                    return true
                }
            }
        } catch (_: Exception) {
        }
        return false
    }
}

package com.wolver.touchguard

import android.app.Activity
import android.app.AlertDialog
import android.content.Context
import android.content.Intent
import android.net.Uri
import android.os.Handler
import android.os.Looper
import org.json.JSONObject
import java.io.BufferedReader
import java.io.InputStreamReader
import java.net.HttpURLConnection
import java.net.URL

object UpdateManager {

    private const val VERSION_CHECK_URL =
        "https://raw.githubusercontent.com/Wolverh/WolverTouchGuard/main/version.json"

    data class UpdateInfo(
        val hasUpdate: Boolean,
        val latestVersionCode: Int,
        val latestVersionName: String,
        val downloadUrl: String,
        val changelog: String
    )

    fun check(context: Context, callback: (UpdateInfo?) -> Unit) {
        val mainHandler = Handler(Looper.getMainLooper())

        Thread {
            try {
                val url = URL(VERSION_CHECK_URL)
                val conn = url.openConnection() as HttpURLConnection
                conn.connectTimeout = 8000
                conn.readTimeout = 8000
                conn.requestMethod = "GET"
                conn.useCaches = false

                if (conn.responseCode == 200) {
                    val reader = BufferedReader(InputStreamReader(conn.inputStream))
                    val response = reader.readText()
                    reader.close()

                    val json = JSONObject(response)
                    val remoteCode = json.optInt("versionCode", 0)
                    val remoteName = json.optString("versionName", "")
                    val downloadUrl = json.optString("downloadUrl", "")
                    val changelog = json.optString("changelog", "Bug fixes and improvements")

                    val currentCode = BuildConfig.VERSION_CODE
                    val hasUpdate = remoteCode > currentCode

                    val info = UpdateInfo(
                        hasUpdate = hasUpdate,
                        latestVersionCode = remoteCode,
                        latestVersionName = remoteName,
                        downloadUrl = downloadUrl,
                        changelog = changelog
                    )

                    mainHandler.post { callback(info) }
                } else {
                    mainHandler.post { callback(null) }
                }
            } catch (_: Exception) {
                mainHandler.post { callback(null) }
            }
        }.start()
    }

    fun showUpdateDialog(activity: Activity, info: UpdateInfo) {
        AlertDialog.Builder(activity)
            .setTitle("🚀 New Update Available (v${info.latestVersionName})")
            .setMessage("${info.changelog}\n\nClick 'Update Now' to download and install with 1-click.")
            .setPositiveButton("Update Now") { _, _ ->
                try {
                    val intent = Intent(Intent.ACTION_VIEW, Uri.parse(info.downloadUrl))
                    activity.startActivity(intent)
                } catch (_: Exception) {
                }
            }
            .setNegativeButton("Later", null)
            .show()
    }
}
